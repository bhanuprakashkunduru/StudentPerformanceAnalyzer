# Student Performance Analyzer

A web-based Student Performance Analyzer built using Flask, MySQL, HTML, CSS, JavaScript, and Machine Learning.

## Features

- Student performance dashboard
- Add student records
- View student records
- Edit student information
- Delete student records
- Student performance analytics
- Attendance and internal marks charts
- Study hours analysis
- Assignment completion analysis
- Previous percentage analysis
- Student risk prediction using Machine Learning
- Prediction history
- Responsive user interface

## Technologies Used

### Frontend

- HTML
- CSS
- JavaScript
- Chart.js

### Backend

- Python
- Flask

### Database

- MySQL

### Machine Learning

- Python
- Pandas
- Scikit-learn
- Joblib
